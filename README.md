# AI Agent Studio

Платформа для мониторинга и управления автономными AI-агентами с интерактивной панелью операционных метрик и визуализацией данных. Разработана для быстрого развёртывания масштабируемых аналитических интерфейсов и инструментов администрирования.

**Автор:** Дима Евгеньев ([@walsik111](https://github.com/walsik111))

---

## Стек технологий

- **Next.js (App Router)** — современная серверная архитектура и высокая производительность
- **React** — компонентный интерфейс и управление состоянием
- **TypeScript** — строгая статическая типизация
- **Tailwind CSS** — утилитарная стилизация и поддержка тем оформления (Dark / Light)
- **shadcn/ui & Radix UI** — доступные модульные UI-компоненты
- **Recharts** — визуализация графиков и аналитических показателей
- **Lucide React** — векторные иконки интерфейса

## Локальный запуск

### 1. Клонирование репозитория

```bash
git clone https://github.com/walsik111/ai-agent-studio.git
cd ai-agent-studio
```

### 2. Установка зависимостей

Для работы проекта рекомендуется использовать `pnpm`:

```bash
pnpm install
```

### 3. Запуск сервера разработки

```bash
pnpm dev
```

После запуска приложение будет доступно по адресу: [http://localhost:3000](http://localhost:3000).

### 4. Сборка для продакшена

```bash
pnpm build
pnpm start
```
